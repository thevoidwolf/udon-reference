# Type Identity

Udon's VM does not implement C#'s normal runtime type system across `UdonSharpBehaviour` user types — there is no fast `behaviour is MyScript` check and no `(MyScript)behaviour` cast that works generally at runtime. To work around this, `UdonSharpBehaviour` exposes a deterministic numeric **type ID** and a string **type name**, both computed at compile time from the class's full type name.

Source: `Runtime/UdonSharpBehaviour.cs` and `Runtime/UdonSharpRuntimeUtils.cs`. **[Source]**

---

## `GetUdonTypeID`

```csharp
public long GetUdonTypeID()
public static long GetUdonTypeID<T>() where T : UdonSharpBehaviour
```

Returns a stable 64-bit hash of the class's `Type.FullName`. The hash is `SHA-256(typeName)` truncated to the first 8 bytes (`BitConverter.ToInt64`).

- Returns `0` for behaviours whose program is a graph program rather than U#.
- Two clients running the same world will compute the same ID for the same class.
- Renaming or moving a class to a different namespace **changes its ID**.

**Use case:** check what user type an `UdonBehaviour` (or `UdonSharpBehaviour`) reference actually is at runtime.

```csharp
public UdonBehaviour someBehaviour;

void Start() {
    long id = (long)someBehaviour.GetProgramVariable("__udonTypeID__"); // generated by compiler
    if (id == UdonSharpBehaviour.GetUdonTypeID<MyScript>()) {
        // handle MyScript case
    }
}
```

In practice U# generates this comparison for you when you write `if (behaviour is MyScript ms)`-equivalent code through typed references; you usually only call `GetUdonTypeID` explicitly when handing references around through `UdonBehaviour` columns.

## `GetUdonTypeName`

```csharp
public string GetUdonTypeName()
public static string GetUdonTypeName<T>() where T : UdonSharpBehaviour
```

Returns `type.Name` — the **unqualified** class name. Two unrelated classes in different namespaces with the same short name will collide. Prefer `GetUdonTypeID` for equality checks and only use the name for debug logging.

```csharp
Debug.Log($"This is a {GetUdonTypeName()}");   // "This is a Greeter"
```

---

## Implementation note

The hash is computed by `UdonSharp.Internal.UdonSharpInternalUtility.GetTypeID`:

```csharp
public static long GetTypeID(System.Type type)
{
    SHA256 typeHash = new SHA256CryptoServiceProvider();
    byte[] hash = typeHash.ComputeHash(Encoding.UTF8.GetBytes(type.FullName));
    return BitConverter.ToInt64(hash, 0);
}
```

Source: `Runtime/UdonSharpRuntimeUtils.cs`. **[Source]**

The first 8 bytes of an SHA-256 give 64 bits of entropy — collisions across two U# class names in a realistic project are vanishingly unlikely. The hash is not cryptographically meaningful here; SHA-256 was chosen as a stable, available, deterministic hash, not a security primitive.
